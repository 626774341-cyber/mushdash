# MushDash · 蘑菇冲刺 🍄🎵

一个类似 Muse Dash 的**竖屏 3D 节奏跑酷**网页游戏。纯 HTML5 Canvas + Web Audio 实现
（3D 为手写透视投影，零依赖、无构建步骤）——双击 `index.html` 即可开玩。

**在线试玩**：<https://626774341-cyber.github.io/mushdash/>

## 玩法

小蘑菇女孩在 3D 赛道上向前奔跑，镜头从她正后方越肩跟随；敌人沿**左右两条车道**
迎面袭来：左道的紫色怒菌、右道的黄色飞菇。

| 按键 | 动作 | 对付 |
|---|---|---|
| `A` / `←`（或 `F`） | 左道斩击 | 左车道的紫色怒菌 |
| `D` / `→`（或 `J`） | 右道斩击 | 右车道的黄色飞菇 |
| `ESC` / `P` | 暂停 | — |

- 触屏设备：点按屏幕**左半边**打左道，**右半边**打右道。
- 判定分 **PERFECT / GREAT / GOOD**，越准分越高；漏怪扣血、断连击。
- 星星糖果要按**对应车道**的键才吃得到（纯加分奖励）；连击每 +50 回 4 点血。
- 攒满热情槽触发 **FEVER**：10 秒双倍得分 + 金色舞台。
- 戴金冠的**菇霸**（长按怪）：到场时**按住对应车道不放**把它压扁，撑到倒计时结束
  拿到「完美长按 +300」；**提前松手它会弹起来反击**（扣血断连击）。
- 全程无 MISS 通关会点亮 **FULL COMBO** 徽章。

## 大厅：选曲 × 角色 × 难度

**五首曲目**，各自拥有独立的 BPM、旋律、音色与配色主题：

| 曲目 | BPM | 主题 | 风格 |
|---|---|---|---|
| 🌻 草原漫步 Meadow Walk | 128 | 清新草原 | 明亮 C 大调，舒缓入门 |
| 🌆 霓虹疾走 Neon Rush | 138 | 黄昏城市 | A 小调，标准手感 |
| 💚 酸柠狂潮 Acid Lime | 148 | 酸性绿舞池 | club 式洗脑 riff，hyper 节拍 |
| 🌙 午夜狂奔 Midnight Dash | 152 | 星空午夜 | E 小调锯齿波电音，高速高压 |
| 🌫️ 雾蓝 Swag SWAG III · Homage | 92 | 雾蓝私密度假夜 | 慢热 R&B：808 长低音 + 摇摆镲 + 激光合成器 |

编曲覆盖电子舞曲与 R&B 两大系：四踩底鼓 + 侧链泵感 + 副歌酸性贝斯 +
失谐和声 stab + 主旋律回声（电子系）；808 长低音 + 16 分摇摆镲 +
切分 groove + laser synth 扫频（R&B 系）。

**三位演出者**，能力各异：

| 角色 | 定位 | 特性 |
|---|---|---|
| 波波 | 元气蘑菇 | 生命 100，各项均衡 |
| 蓝莓 | 星光法师 | 生命 80，Fever 积攒 +40%，糖果双倍 |
| 岩岩 | 坚壁卫士 | 生命 130，漏怪伤害减半，Fever −20% |

- 每首曲目 × 每个难度的**最佳成绩与评级**自动存档，显示在大厅中。
- **判定偏移校准**（±300ms）：蓝牙耳机等音频延迟导致判定总偏早/偏晚时可调。
- 难度三档：轻松 / 普通 / 狂热（敌速与谱面密度不同）。
- **版本记录**：标题界面点击「版本号 · 更新记录」查看每个版本的变更，
  详细日志见 [CHANGELOG.md](CHANGELOG.md)。

## 音乐

背景音乐是 Web Audio 实时合成的 chiptune：鼓、贝斯、主旋律、和声垫全部
程序生成，曲目间切换和弦进行、旋律与主音色（方波/锯齿波）。
谱面节拍与音频时钟严格同步，暂停使用 `AudioContext.suspend()`，恢复零漂移。
右上角 🔊 可一键静音。

## 运行

- **直接玩**：双击 `index.html`（Chrome / Edge / Safari 均可）。
- 或起本地服务器：`python3 -m http.server 8765` 后访问
  <http://127.0.0.1:8765/>。

## 代码结构

```
index.html      页面骨架：标题 / 大厅 / 暂停 / 结算
css/style.css   卡通风格 UI（9:16 竖屏布局）
js/chart.js     曲目定义（配色/音乐素材/速度）+ 谱面生成器
js/audio.js     Web Audio 合成器：chiptune BGM 调度 + 全部音效
js/game.js      游戏核心：大厅流程、判定、3D 透视渲染、HUD、存档
```

调试辅助：URL 加 `?testclock=1` 进入静默高速时钟模式（40 倍速、不发声），
配合控制台里的 `window.__mushdash` 钩子可脚本化跑完整局，正常游玩不受影响。
