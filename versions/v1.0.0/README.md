# MushDash · 蘑菇冲刺 🍄🎵

一个类似 Muse Dash 的**节奏跑酷**网页游戏。纯 HTML5 Canvas + Web Audio 实现，
零依赖、无构建步骤——双击 `index.html` 即可开玩。

## 玩法

小蘑菇女孩在左侧自动奔跑，敌人沿**上下两条轨道**从右侧随音乐节拍袭来：

| 按键 | 动作 | 对付 |
|---|---|---|
| `←` / `A` / `F`（或 `↑` `W`） | 跳劈 | 空中的黄色飞菇 |
| `→` / `D` / `J`（或 `↓` `S`） | 下斩 | 地面的紫色怒菌 |
| `ESC` / `P` | 暂停 | — |

- 触屏设备：点按屏幕**左半边**打空中，**右半边**打地面。
- 判定分 **PERFECT / GREAT / GOOD**，越准分越高；漏怪扣血、断连击。
- 星星糖果路过自动收集；连击每 +50 回 4 点血。
- 攒满热情槽触发 **FEVER**：10 秒双倍得分 + 金色舞台。
- 连打链（绿色串珠）需要跟着节拍连按同一轨道，全斩有额外奖励。
- 三个难度：轻松 / 普通 / 狂热（敌人速度与谱面密度不同），最高分按难度存本地。

## 音乐

背景音乐是 Web Audio 实时合成的 chiptune（138 BPM，A 小调，
Am–F–C–G 和弦进行），鼓、贝斯、主旋律、和声垫全部程序生成；
谱面节拍与音频时钟严格同步，暂停使用 `AudioContext.suspend()`，
恢复零漂移。右上角 🔊 可一键静音。

## 运行

- **直接玩**：双击 `index.html`（Chrome / Edge / Safari 均可）。
- 或起本地服务器：`python3 -m http.server 8765` 后访问
  <http://127.0.0.1:8765/>。

## 代码结构

```
index.html      页面骨架与菜单/结算界面
css/style.css   卡通风格 UI
js/chart.js     谱面生成：48 小节歌曲结构 + 分难度模式库（敌人与节拍对齐）
js/audio.js     Web Audio 合成器：chiptune BGM 调度 + 全部音效
js/game.js      游戏核心：状态机、判定、角色/敌人绘制、粒子、HUD
```

调试辅助：URL 加 `?testclock=1` 进入静默高速时钟模式（40 倍速、不发声），
配合控制台里的 `window.__mushdash` 钩子可脚本化跑完整局，正常游玩不受影响。
